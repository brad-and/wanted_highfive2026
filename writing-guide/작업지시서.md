## .gitignore 설정 (처음 한 번만)

**레포를 처음 clone한 후 반드시 아래 파일을 만들어야 한다.**  
`workfiles/` 안의 개인 파일(사진/음성/메모)이 GitHub에 올라가지 않도록 막는다.

`conference_review/github_page/.gitignore` 파일을 열어서 아래 내용이 있는지 확인:

```
# workfiles — 폴더 구조는 유지, 내부 파일은 push 금지
workfiles/**
!workfiles/
!workfiles/*/
!workfiles/*/.gitkeep
```

없으면 추가한다. (레포에 이미 포함되어 있으면 그냥 넘어가도 됨)

## 세션 원본 자료 정리

작업 전에 현장에서 수집한 자료를 `workfiles/` 안 **본인 이름 폴더**에 넣어둔다.

```
conference_review/github_page/workfiles/
├── aws-summit-2026/
│   ├── daniel/             ← daniel.007 개인 작업 폴더
│   │   ├── 사진/
│   │   ├── 메모.txt
│   │   └── 현장녹음.m4a
│   └── zero/               ← zero.002 개인 작업 폴더
│       ├── 사진/
│       └── 메모.txt
├── wanted_highfive_2026/
└── WIS2026_notion/
```

> `workfiles/` 안의 파일은 `.gitignore`에 의해 **자동으로 push 제외**된다.  
> 폴더 구조(빈 폴더)만 GitHub에 올라간다.

### 개인 작업 폴더 — Claude Code 자동 인식

Claude Code에 프롬프트를 입력할 때 **산출물 저장 위치**를 명시하면,  
Claude Code가 아래 작업을 자동으로 수행한다:

1. `workfiles/aws-summit-2026/[본인이름]/` 폴더를 원본 자료 소스로 인식
2. 해당 폴더 경로를 `.gitignore`에 자동 추가 (이미 있으면 스킵)
3. 세션 완성본(`index.html` + `videos/`)만 `github_page/aws/[세션폴더]/`에 출력

**GitHub에 실제로 올라가는 것:**
```
github_page/aws/[세션폴더명]/
  index.html     ← 세션 리뷰 페이지 (이미지 base64 포함)
  videos/        ← 동영상 파일 (있는 경우만)
```

## Claude Code 실행 순서

### 1단계 — 파일 업로드

Claude Code 대화창에 아래 파일들을 올린다:
- `SESSION_PRD.md`
- `SESSION_TEMPLATE.html`
- 현장 사진 파일들 (`workfiles/aws-summit-2026/` 안에 있는 것)
- 메모 (텍스트 붙여넣기 또는 파일)
- 동영상 파일 (선택)

### 2단계 — 프롬프트 입력

아래 텍스트를 복사해서 세션 정보만 채워 넣고 전송:

```
첨부한 SESSION_PRD.md와 SESSION_TEMPLATE.html을 참고해서
AWS Summit Seoul 2026 세션 리뷰 페이지를 만들어줘.

세션 정보:
- 세션명: [예: Bedrock으로 RAG 파이프라인 구축하기]
- 발표자: [이름 · 소속]
- 트랙: [예: AI/ML]
- 날짜: [Day 1 (5/20) / Day 2 (5/21)]
- 참석자: [daniel.007 / zero.002]

내 노트:
[여기에 메모 붙여넣기]

원본 자료 폴더 (내 개인 작업 폴더):
- workfiles/aws-summit-2026/[본인이름]/

산출물 저장 위치:
- HTML: conference_review/github_page/aws/[세션폴더명]/index.html
- 동영상 있으면: 같은 폴더 안에 videos/ 서브폴더 생성
  (예: conference_review/github_page/aws/01-bedrock-rag/index.html)

추가 작업:
- 원본 자료 폴더(workfiles/aws-summit-2026/[본인이름]/)를 .gitignore에 추가해줘
  (이미 있으면 스킵)
- GitHub에는 index.html과 videos/ 파일만 올라가도록 확인
```

> **세션 폴더명 규칙**: `숫자두자리-영문키워드` (예: `01-bedrock-rag`, `02-eks-upgrade`)  
> 한글·공백·특수문자 금지

### 3단계 — 허브 페이지 업데이트

세션 페이지 완성 후, `github_page/aws/index.html`을 열어서  
새 세션 카드를 추가한다. (`SESSION_PRD.md` 9번 섹션 참고)

### 4단계 — 로컬 파일 확인 (push 전 필수)

push 전에 반드시 로컬에서 브라우저로 직접 확인한다.

```
file:///[내 컴퓨터 경로]/conference_review/github_page/aws/[세션폴더명]/index.html
```

확인 항목:
- [ ] 세션 페이지 전체 레이아웃 정상
- [ ] 이미지 전부 표시됨 (깨진 이미지 없음)
- [ ] 갤러리 클릭 시 라이트박스 정상 동작
- [ ] nav 링크 정상 (`← 아카이브 / AWS Summit Seoul 2026 / 세션명`)
- [ ] 동영상 있는 경우 재생 확인

> **Claude Code 사용 시**: 파일 수정 후 로컬 파일 경로를 먼저 공유하고,  
> push 여부를 확인받은 후 진행한다. 자동으로 push하지 않는다.

### 5단계 — push

로컬 확인 완료 후 push:

```bash
cd conference_review
git add .
git commit -m "add AWS Summit session: [세션명]"
git push origin main
```

## 폴더 구조 전체

```
conference_review/
├── index.html                    ← 리다이렉트 (→ main_index.html)
├── .gitignore                    ← workfiles 파일 제외 설정
├── github_page/                  ← ✅ GitHub push 대상 (이 폴더 자체가 git repo)
│   ├── main_index.html           ← 메인 허브 (팀 컨퍼런스 아카이브)
│   ├── aws/
│   │   ├── index.html            ← AWS 허브
│   │   ├── 01-session-name/
│   │   │   ├── index.html        ← 완성된 세션 페이지 ✅ push 대상
│   │   │   └── videos/           ← 동영상 ✅ push 대상
│   │   └── 02-session-name/
│   │       └── index.html
│   ├── highfive/
│   ├── notion/
└── writing-guide/                ← ✅ 가이드 문서
    ├── 작업지시서.md
    ├── SESSION_PRD.md
    └── SESSION_TEMPLATE.html
└── workfiles/                ← 🗂 폴더만 push, 파일은 제외 (파일은 개인별로 세션 raw데이터 저장)
```

## 주의사항

- 이미지는 반드시 **base64 embed** — 로컬 경로(`C:\...`, `/Users/...`) 절대 금지
- 동영상: 100MB 미만만 `videos/` 폴더에 복사 가능 / 초과 시 Claude Code가 압축 안내
- 경로에 한글·공백 금지 (폴더명, 파일명 모두)
- `workfiles/` 안 파일은 절대 push 안 됨 (gitignore 처리)
