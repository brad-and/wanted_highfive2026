## 세션 원본 자료 정리

현장 자료를 `workfiles/aws-summit-2026/` 안에 자유롭게 넣는다.

```
workfiles/aws-summit-2026/
├── 사진/          ← 현장 사진 JPG
├── 메모.txt       ← 강의 노트
└── 녹음.m4a      ← 현장 녹음 (선택)
```

> `workfiles/` 안의 파일은 `.gitignore`에 의해 **자동으로 push 제외**된다.

### Claude Code 작업 기준 (자동 적용)

Claude Code는 아래 기준으로 작업한다:

**세션 정보 파악**
- 공식 아젠다 참고: https://aws.amazon.com/ko/events/summits/seoul/agenda/
- `workfiles/aws-summit-2026/` 안의 사진·메모·녹음을 토대로 세션 내용 유추

**산출물 저장 위치**
- `github_page/aws/[세션폴더명]/index.html`
- 동영상 있으면: `github_page/aws/[세션폴더명]/videos/`
- 세션폴더명 규칙: `숫자두자리-영문키워드` (예: `01-bedrock-rag`)

**작업자가 전달해야 하는 것 (3가지만)**
1. Day 1 (5/20) 또는 Day 2 (5/21)
2. 참석자 이름 (daniel.007 / zero.002)
3. workfiles 폴더 안에 뭐가 있는지 설명

Claude Code에 전달할 프롬프트는 별도 슬랙 메시지 참고.

## 로컬 확인 → push

Claude Code가 로컬 링크를 띄워주면 브라우저에서 확인:

- [ ] 사진 정상 표시 (깨진 이미지 없음)
- [ ] 갤러리 클릭 시 라이트박스 정상
- [ ] nav 링크 정상 (`← 컨퍼런스 목록 / AWS Summit Seoul 2026 / 세션명`)
- [ ] 동영상 있는 경우 재생 확인

이상 없으면 Claude Code에 "push해줘" 입력.

```bash
git add .
git commit -m "add AWS Summit session: [세션명]"
git push origin main
```
